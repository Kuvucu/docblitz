# DocBlitz — генератор КП, счетов и актов

Статический сайт (HTML/CSS/JS), сервер не нужен.

- `index.html` — лендинг с тарифами
- `app.html` — генератор: КП / Счёт / Акт, НДС, скидка, сумма прописью, логотип, история, PDF (через «Печать → Сохранить как PDF»)

Запуск: открыть `index.html` в браузере.
