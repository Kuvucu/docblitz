# DocBlitz Bot — КП, счета и акты в PDF прямо в Telegram

Бот спрашивает тип документа, клиента, позиции и НДС и присылает готовый PDF с суммой прописью.
Бесплатно 5 документов в месяц, Pro (безлимит, без подписи бота) — оплата в Telegram Stars.

## Запуск
1. Создайте бота у @BotFather, токен положите в `token.txt` рядом с `bot.py` (или в переменную `BOT_TOKEN`).
2. `pip install -r requirements.txt`
3. `python bot.py` (на Windows — `run.bat`).

Переменные окружения: `ADMIN_ID` — ваш Telegram id (уведомления об оплатах, `/stats`), `PRO_STARS` — цена Pro в звёздах (по умолчанию 150).

Данные хранятся в `bot.db` (SQLite). Бот работает, пока запущен процесс: для работы 24/7 нужен сервер (VPS).

## Команды
`/new` новый документ · `/settings` реквизиты · `/history` история · `/demo` пример · `/pro` тариф · `/paysupport` · `/stats` (админ)
